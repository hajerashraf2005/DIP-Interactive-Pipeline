# DIP-Interactive-Pipeline
An interactive Digital Image Processing application using Python, OpenCV, and CustomTkinter.
# Digital Image Processing – Interactive Pipeline

## Project Overview
An interactive Digital Image Processing application developed using Python. It provides a graphical interface that allows users to load images and apply different image processing techniques.

## Features

### Point Processing
- Histogram Equalization
- Log Transformation
- Gamma Correction

### Smoothing
- Average Blur
- Gaussian Blur
- Median Filter

### Sharpening and Edge Detection
- Laplacian Filter
- Sobel Edge Detection
- Unsharp Masking

### Morphological Operations
- Erosion
- Dilation

### Additional Features
- Load images from the computer.
- Reset images to their original state.
- Apply multiple filters sequentially.
- Display processed images through a graphical interface.

## Technologies Used
- Python
- OpenCV
- NumPy
- CustomTkinter
- Pillow

## Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

## How to Run

Run the following command:

```bash
python main.py
```

## Project Purpose
This project demonstrates practical applications of Digital Image Processing concepts through an interactive graphical interface.
